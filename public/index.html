Panduan Cepat Integrasi

Cara menyematkan aset CDN TEN ke aplikasi web Anda

🎨 Import CSS Global

Gunakan stylesheet inti TEN di tag <head> proyek HTML Anda:

<link rel="stylesheet" href="https://cdn.ten.my.id/assets/css/ten-core.css">

⚙️ Muat Script Utility

Gunakan library JavaScript bersama di bagian bawah <body>:

<script src="https://cdn.ten.my.id/assets/js/ten-utils.js"></script>

🖼️ Tampilkan Logo Vektor

Sematkan logo resmi SVG dengan loading performa tinggi:

<img src="https://cdn.ten.my.id/assets/brand/logo-ten.svg" alt="TEN" width="160">
